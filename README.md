# r00tvpn-referrals — «Приведи друга» для панели Mikan

Аддон для [Mikan](https://github.com/Miroshka000/mikan) (протокол аддонов 2), который ведёт
реферальную программу r00tvpn сам, без ручной работы администратора.

## Как это работает

1. Подписчик пишет отдельному боту приглашений (например, `@r00tvpn_friends_bot`) `/start` и получает
   **личную ссылку** вида `https://t.me/r00tvpn_friends_bot?start=r<код>` и свою статистику.
2. Друг открывает ссылку. Если он **новый клиент** (нет подписки или только пробный тариф), бот
   запоминает, кто его пригласил, и выдаёт ему общий **промокод** (например, `FRIEND30`, −30% на первую
   оплату). Пригласившему приходит «По вашей ссылке пришёл друг».
3. Когда друг **впервые оплачивает подписку** (событие панели `payment.paid`, вид `new` или `renew`),
   аддон продлевает подписку пригласившего на заданное число дней (по умолчанию 14) и пишет ему
   «Ваш друг оплатил подписку — вам +14 дней».

Защита от повторов: друг засчитывается одному пригласившему один раз (первая ссылка); начисление
идёт с ключом `ref-<id друга>`, и панель не начислит по нему второй раз. Уже платящий клиент
«другом» не становится. Пакеты трафика и платный пробный период не считаются.

## Установка

1. Создайте бота в [@BotFather](https://t.me/BotFather) — отдельного от бота сервиса.
2. В Mikan создайте промокод для друзей: «Платежи → Промокоды → Создать»: процентная скидка 30,
   только первая покупка, лимит на клиента 1.
3. В Mikan: «Аддоны» → установите свой образ по digest (его показывает запуск `image` в Actions):
   `ghcr.io/soulless4235/r00tvpn-referrals@sha256:…`, вид `generic`, режим `http`, разрешения
   `users:all`, `users:grant`, `events`, `kv`, `ui`.
4. Откройте страницу аддона «Приведи друга» в админке и впишите токен бота, промокод, число дней.
   Страница сразу покажет, принял ли Telegram токен.
5. В боте сервиса добавьте кнопку-ссылку на бота приглашений.

## Разрешения

| Разрешение | Зачем |
|---|---|
| `users:all` | найти подписку по Telegram id: есть ли у человека подписка, новый ли он клиент |
| `users:grant` | продлить подписку пригласившего на N дней |
| `events` | узнать об оплатах (`payment.paid`) |
| `kv` | хранить настройки, коды ссылок, кто кого пригласил и статистику (в хранилище панели) |
| `ui` | страница настроек и итогов в админке |

Токен бота хранится в KV-хранилище панели (оно входит в бэкап панели) и никогда не отдаётся странице.
Аддон хранит Telegram id пригласивших и приглашённых — только для начисления дней.
